# Crowbar Heist Kit

48 transparent PNG components at 2× display resolution. Large buttons are 384×128, round buttons 160×160. Render at half these dimensions for nominal UI size. Nine-slice margins are in heist-ui-nineslice.json, ordered left/top/right/bottom. Keep corner sizes fixed when stretching.

Files ending _strip8 contain eight horizontal equal-size frames with no spacing. Read frame width as image.width / 8. The timer digit sheet has 11 cells of 48×80, ordered 0123456789:. Text-free panels take runtime labels.
